# VORLI Next — prototipo mobile-first

Data: 9 ottobre 2026. Questo prototipo è confinato in `preview/vorli-next/`, separato dal sito pubblico `site/`.

Aprire `index.html` in locale o usare `python3 -m http.server 8000 -d preview/vorli-next`. Pagine: home, catalogo demo, risorse, metodo e landing USB-C. Il CSS non carica font, script, foto o servizi esterni. L'illustrazione SVG nella home è originale e incorporata.

I quattro documenti linkati sono file Markdown già verificati su altri branch. Non sono PDF, non sono offerte e non sono in vendita. Nessun link affiliato, carrello, pagamento, prezzo o dato personale è presente. L'anteprima è noindex e non viene distribuita con GitHub Pages.
