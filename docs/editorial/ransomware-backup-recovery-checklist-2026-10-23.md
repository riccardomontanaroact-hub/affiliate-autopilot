## Un backup non serve se non puoi ripristinarlo
Un ransomware può rendere inaccessibili documenti e applicazioni. Una copia sincronizzata continuamente non è sempre sufficiente: cancellazioni e modifiche indesiderate possono propagarsi. Per questo conta avere copie recuperabili, protette da modifiche accidentali o malevole, e **provare il ripristino** prima che serva.

La guida #StopRansomware della CISA raccomanda backup offline e cifrati dei dati critici, verificandone regolarmente disponibilità e integrità. È una buona base per costruire una routine semplice, adattata alle proprie necessità.

## Otto controlli
1. **Inventario:** elenca i file davvero indispensabili, non soltanto le cartelle più grandi.
2. **Frequenza:** scegli ogni quanto salvare i dati in base a quante modifiche puoi permetterti di perdere.
3. **Copia separata:** conserva almeno una copia non sempre accessibile dal computer principale.
4. **Protezione:** cifra i supporti dove opportuno e custodisci le credenziali in modo sicuro.
5. **Versioni:** verifica se puoi tornare a una versione precedente alla modifica indesiderata.
6. **Accessi:** limita i permessi di cancellazione o modifica delle copie di sicurezza.
7. **Test:** prova a recuperare alcuni file di prova e annota quanto tempo serve.
8. **Piano di emergenza:** conserva istruzioni di recupero accessibili anche se il computer principale è fuori uso.

### Prova di ripristino di 15 minuti
Crea un documento fittizio, esegui un backup, modifica o elimina **solo la copia di prova**, quindi verifica di poter ripristinare la versione precedente in una cartella distinta. Non usare dati sensibili o importanti per l'esperimento. Se non funziona, correggi la procedura prima di fidarti del backup.

### Checklist stampabile
- [ ] File prioritari identificati
- [ ] Frequenza di backup definita
- [ ] Copia offline o altrimenti isolata disponibile
- [ ] Protezione e accessi verificati
- [ ] Cronologia versioni controllata
- [ ] Ripristino di prova riuscito
- [ ] Tempi di recupero annotati
- [ ] Istruzioni d'emergenza conservate separatamente

**Limiti:** nessuna soluzione garantisce immunità dal ransomware; non suggerire che il pagamento del riscatto assicuri il recupero. In caso di incidente reale, isolare i dispositivi coinvolti e rivolgersi a professionisti competenti.
