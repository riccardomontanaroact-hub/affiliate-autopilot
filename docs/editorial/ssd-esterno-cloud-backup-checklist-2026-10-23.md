**Meta description:** SSD esterno e backup cloud non sono alternative perfette: confronta ripristino, sicurezza, costi e comodità con una checklist pratica.

## Una copia dei file non basta sempre

Un SSD esterno consente di conservare una copia locale e di ripristinare i dati senza dipendere dalla connessione Internet. Un backup cloud, se correttamente configurato, può proteggere anche da un danno che coinvolge casa o ufficio. Entrambe le soluzioni presentano limiti: un SSD può guastarsi o andare perso, mentre un servizio cloud dipende da credenziali, connettività, termini contrattuali e procedure di recupero.

La scelta non dovrebbe basarsi solo sui gigabyte. Prima di acquistare, chiediti quali file vuoi proteggere, quanto spesso cambiano e quanto rapidamente devi poterli recuperare.

## Otto controlli utili

1. **Capacità reale necessaria.** Misura lo spazio usato dai file e considera la crescita futura.
2. **Frequenza dei backup.** Una copia aggiornata raramente potrebbe non salvare le modifiche recenti.
3. **Ripristino di prova.** Controlla che un file di test possa essere recuperato e aperto.
4. **Sicurezza fisica.** Conserva l'unità esterna in luogo protetto; scollegala dopo il backup.
5. **Protezione dell'accesso.** Valuta cifratura, password robuste e recupero delle chiavi.
6. **Backup fuori sede.** Una seconda copia in luogo differente riduce il rischio di perdita simultanea.
7. **Costi nel tempo.** Confronta costo iniziale dell'unità, rinnovi del cloud e limiti di spazio.
8. **Compatibilità.** Verifica porte, sistemi operativi e software di backup prima dell'acquisto.

## Perché evitare di lasciare sempre collegato il disco

Un supporto collegato in modo permanente può risultare accessibile anche a malware o ransomware. Una copia scollegata dopo il backup aggiunge una barriera, ma deve essere aggiornata regolarmente e conservata in modo sicuro.

## Checklist scaricabile o stampabile

- [ ] Ho identificato i file davvero importanti.
- [ ] Ho definito ogni quanto effettuare il backup.
- [ ] Dispongo di almeno una copia separata dal dispositivo principale.
- [ ] So dove sono conservate le chiavi di recupero.
- [ ] Ho provato il ripristino con file di test.
- [ ] Ho valutato rischi fisici e connessione Internet.
- [ ] Ho controllato costi ricorrenti e compatibilità.
- [ ] Ho verificato quando il backup è stato eseguito l'ultima volta.

**Conclusione:** un SSD esterno e un servizio cloud possono completarsi. Nessuna soluzione elimina la necessità di verificare periodicamente che il recupero funzioni.
