## Che cosa significa davvero «cloud privato»?

Molti servizi parlano di file protetti o di cifratura. È utile, ma non descrive da sola chi possa leggere i contenuti, come vengano custodite le chiavi e cosa accada se perdi l'accesso. Prima di pagare, cerca risposte precise nella documentazione tecnica del servizio.

Una distinzione importante è tra **cifratura durante il trasferimento**, **cifratura sui server** e sistemi in cui **solo l'utente controlla le chiavi necessarie a leggere i file**. Le espressioni commerciali, incluso «zero knowledge», vanno valutate in base all'implementazione dichiarata e a eventuali verifiche indipendenti. Non sono una garanzia assoluta.

## Le nove domande da fare

1. **Chi può decifrare i contenuti?** Controlla se il fornitore gestisce chiavi utilizzabili per leggere i file o se le chiavi rimangono esclusivamente sotto il tuo controllo.
2. **Che cosa succede se dimentichi la password?** La facilità di recupero dell'account può comportare compromessi diversi; verifica anche se perdere le credenziali può rendere irrecuperabili i dati.
3. **Quali dati restano visibili?** Dimensione, nomi dei file, orari e informazioni di condivisione potrebbero non avere la stessa protezione del contenuto.
4. **La condivisione cambia le garanzie?** Verifica se i link pubblici, gli inviti e le anteprime richiedono processi di decifratura differenti.
5. **È disponibile l'autenticazione a più fattori?** Cerca impostazioni per proteggere l'accesso e per revocare sessioni o dispositivi.
6. **Quanto dura la cronologia versioni?** Controlla le possibilità di recupero dopo una modifica o una cancellazione accidentale.
7. **Esiste un backup indipendente?** Una cartella sincronizzata può propagare errori o cancellazioni; conserva una copia separata dei documenti essenziali.
8. **Come si esportano i dati?** Prima di sottoscrivere un piano, verifica limiti, formati, costi e procedura per uscire dal servizio.
9. **Qual è il costo dopo la promozione?** Distingui prezzo iniziale, rinnovi, spazio, limiti d'uso, assistenza e politica di rimborso.

## Mini-test senza rischi

Usa una cartella di **file fittizi**: caricala, attiva le protezioni disponibili, condividi un solo file di prova, revoca la condivisione e verifica che tu possa recuperare una versione precedente. Non usare documenti personali o dati sensibili durante la prova. Per valutazioni di sicurezza avanzate, non sostituire una verifica professionale con un test superficiale.

## Checklist stampabile

- [ ] Ho capito chi controlla le chiavi.
- [ ] Conosco la procedura di recupero account e i suoi limiti.
- [ ] Ho verificato il trattamento dei metadati.
- [ ] Ho controllato condivisione e revoca dei link.
- [ ] Ho attivato, se disponibile, l'autenticazione a più fattori.
- [ ] Conosco durata di versioni e cestino.
- [ ] Ho una copia di backup separata.
- [ ] Ho provato l'esportazione con file fittizi.
- [ ] Conosco prezzo di rinnovo e condizioni contrattuali.
