# Pubblicazione gratuita con GitHub Pages

1. Crea un account GitHub gratuito.
2. Crea un repository pubblico, per esempio `affiliate-autopilot`.
3. Carica il progetto nel repository.
4. In Settings → Pages scegli la pubblicazione dal branch principale.
5. GitHub fornirà un indirizzo `*.github.io` gratuito.

Per la versione iniziale è consigliabile pubblicare il progetto e non inserire token o password nel repository.
