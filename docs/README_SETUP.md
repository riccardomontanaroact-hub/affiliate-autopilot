# Setup iniziale

## Dati che devi fornire tu
- nome/brand del sito
- email di contatto
- eventuale nicchia preferita (altrimenti il motore può partire da una nicchia generale)
- gli ID/tag affiliati ottenuti dai network che approvano il tuo account

## Non fornire mai qui
- password
- codici 2FA
- numeri completi di carte
- chiavi private

## Strategia gratuita
Partire con GitHub Pages e un catalogo piccolo. L'automazione completa dei feed/API viene aggiunta solo quando il relativo programma permette l'accesso gratuito e l'uso è conforme ai suoi termini.
