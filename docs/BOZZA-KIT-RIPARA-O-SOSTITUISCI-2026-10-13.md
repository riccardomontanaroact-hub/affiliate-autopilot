## Confronto economico
| Voce (€) | Riparare | Sostituire |
|---|---:|---:|
| Intervento o acquisto | | |
| Diagnosi, spedizione, accessori | | |
| Trasferimento dati e fermo | | |
| Permuta o rivendita (sottrarre) | | |
| **Totale** | | |

Formula: totale = prezzo + spese + trasferimento + fermo - permuta.
Costo mensile stimato = totale / mesi di utilizzo ipotizzati.

Esempio *fittizio*: riparazione 120 + 15 + 10 = 145 € per 18 mesi, circa 8,06 €/mese; sostituzione 340 + 15 - 50 = 305 € per 36 mesi, circa 8,47 €/mese. La durata futura non è garantita.

## Checklist prima di decidere
- Preventivo scritto con IVA, ricambi, tempi e condizioni?
- Batteria, supporto software, affidabilità e sicurezza verificati?
- Garanzia, reso e assistenza documentati?
- Backup testato e dati personali protetti?
- Due alternative realmente confrontabili?

## Sicurezza
Non aprire o ricaricare batterie gonfie o danneggiate: affidarsi a professionisti. Non comunicare password o OTP.

## Avvertenza legale
Il D.Lgs. 176/2026 sul diritto alla riparazione è pubblicato ma entra in vigore **il 22 ottobre 2026**, non il 13 ottobre. I diritti variano secondo categoria e condizioni.
