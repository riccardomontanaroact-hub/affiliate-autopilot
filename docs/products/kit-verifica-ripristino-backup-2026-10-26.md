# Kit VORLI — Verifica pratica di recuperabilità dei backup
**Prodotto digitale originale, bozza compilabile · 26 ottobre 2026 · NON in vendita.**

## Perché serve
Un file sincronizzato nel cloud non equivale necessariamente a un backup recuperabile. Questo kit aiuta a documentare una prova di ripristino usando **solo file di test non sensibili**, senza richiedere account, credenziali o dati personali.

## Scheda 2 — Test sicuro con file fittizi
1. Creare una cartella locale denominata `prova-recupero` con tre file inventati: `esempio.txt`, `tabella.csv`, `nota.md`. Nessun documento reale.
2. Scrivere in ciascun file una stringa fittizia e annotarne il numero di caratteri, senza inserire password o dati privati.
3. Eseguire una copia con il metodo di backup già disponibile (senza comprare servizi).
4. Ripristinare i tre file **in una cartella diversa**: non sovrascrivere originali e non cancellare nulla.
5. Confrontare presenza, apertura e contenuto dei tre file.
6. Annotare tempo impiegato, problemi e soluzione.
7. Ripetere il test dopo cambi importanti di dispositivo o configurazione.

## Requisiti prima di un'eventuale vendita
Creare versione accessibile PDF e foglio editabile senza macro; testare su mobile e con lettori di schermo. Verificare originalità, licenza, IVA, recesso dei contenuti digitali, identità venditore e informazioni precontrattuali. Nessun checkout o consegna automatica attivi.
