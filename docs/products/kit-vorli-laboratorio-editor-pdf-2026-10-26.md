# Kit VORLI — Laboratorio di scelta editor PDF

**Versione:** 0.1, 26 ottobre 2026. **Stato:** prototipo originale compilabile, non in vendita e non distribuito in produzione.  
**Scopo:** confrontare fino a tre editor PDF in modo ripetibile, senza inviare documenti sensibili a terzi.

## Preparazione sicura (10 minuti)

Crea sul tuo dispositivo una cartella chiamata `laboratorio-pdf-fittizi` e quattro documenti senza dati reali:

- `01-testo.pdf`: due pagine con una tabella semplice e la frase «La verifica inizia qui».
- `02-scansione.pdf`: una scansione o immagine PDF di una pagina inventata contenente «Codice prova 4827» e qualche parola accentata.
- `03-modulo.pdf`: un modulo con campi Nome = «Esempio», Città = «Città immaginaria», Note = «Solo test».
- `04-immagine.pdf`: una pagina con una figura disegnata da te e una didascalia.

**Regola privacy:** non usare fatture, referti, contratti o identità reali. Se il programma propone un caricamento cloud, leggi prima le condizioni e usa solo i file fittizi.

## Matrice decisionale personale

Distribuisci **100 punti di importanza** tra i criteri, poi attribuisci a ogni software un voto **0–5** solo sulla base di test documentati. Se non hai verificato un criterio, lascialo «N/D» e **non** calcolare un totale completo.
