## Salvare non basta: bisogna poter recuperare
Una copia dei file è utile solo se, quando serve, si riesce a ripristinarla. Il semplice messaggio «sincronizzazione completata» non dimostra che un file cancellato o corrotto sarà recuperabile. La verifica deve riguardare il recupero reale, senza esporre i documenti importanti.

## Prova di ripristino in cinque passaggi
1. Crea tre piccoli file con contenuto completamente inventato, in una cartella dedicata.
2. Copiali usando il sistema di backup che già utilizzi. Evita di acquistare nuovi servizi solo per la prova.
3. Ripristinali in una **cartella differente** da quella originale.
4. Apri i file e verifica che contenuto e numero di elementi corrispondano.
5. Annota la data, il tempo necessario e gli errori: una prova ripetibile è più utile di un'impressione.

## Cosa controllare oltre al test
- Esiste una copia isolata o offline? Un guasto o un attacco può compromettere copie sempre connesse.
- Puoi recuperare versioni precedenti o file cancellati? Leggi i limiti specifici del fornitore.
- Sai come recuperare l'accesso senza conservare password in chiaro in un foglio condiviso?
- È possibile esportare i dati in un formato leggibile e migrare ad altro servizio?
- Quali costi o limiti esistono per recupero e download?

## Errori comuni
Non usare dati sensibili nei test. Non sovrascrivere gli originali durante la prova. Non trattare la sincronizzazione come sostituto automatico di una strategia di backup. Non attribuire a un servizio funzioni che non sono state controllate sulla sua documentazione.
