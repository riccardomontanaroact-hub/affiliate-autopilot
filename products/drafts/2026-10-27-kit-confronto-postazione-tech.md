## 3. Punteggio trasparente, non scientifico
Attribuisci un punteggio **0–5** a ogni criterio solo quando supportato da dati comparabili. Se manca evidenza, scrivi N/V e non sommare il criterio.

| Criterio | Peso suggerito | A (0–5) | B (0–5) | C (0–5) |
|---|---:|---:|---:|---:|
| Adatto alle applicazioni necessarie | 35% | | | |
| Costo totale | 25% | | | |
| Mobilità/ingombro | 15% | | | |
| Porte e possibilità di upgrade | 15% | | | |
| Assistenza e chiarezza condizioni | 10% | | | |

**Formula facoltativa:** somma(punteggio × peso) / somma(pesi disponibili). Se i criteri non verificati differiscono tra alternative, il confronto è incompleto e non va presentato come classifica affidabile.
