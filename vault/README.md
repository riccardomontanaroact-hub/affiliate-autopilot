# VORLI — Cassetto virtuale commerciale

Questo archivio contiene bozze di prodotti digitali, ricerche sui canali e materiali promozionali originali. **Non è collegato al catalogo di produzione, non attiva pagamenti e non rappresenta guadagni.**

Il repository GitHub è PUBBLICO: anche branch e pull request in bozza possono essere letti da terzi. Non salvare dati personali, coordinate bancarie, token, file riservati o informazioni sui clienti.

Contenuti iniziali, verifica 2026-10-08:
- `products/kit-14-giorni-social.md`: prodotto digitale originale in revisione.
- `products/calendario-kpi.csv`: foglio di lavoro vuoto con 14 righe.
- `opportunities-2026-10-08.md`: opportunità e requisiti verificati.
- `distribution-plan.md`: contenuti organici preparati e criteri di qualità.

Per pubblicare: revisionare contenuti e fonti, definire licenza/prezzo, verificare obblighi fiscali e privacy, collegare venditore e pagamenti in ambiente autorizzato, quindi ottenere approvazione esplicita. Non inserire bozze direttamente in `data/products.json` finché non siano commerciabili.
